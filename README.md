# 1. Project Title

📊 **Sales Analytics: Interactive Sales Dashboard 2025–2026**

An interactive Power BI dashboard designed to analyze sales performance, product categories, brand-wise sales, state-wise distribution, and business profitability.

# 2. Short Description 

The Sales Dashboard 2025–2026 is an interactive Power BI report that provides insights into sales transactions, product quantities, total sales, costs, and profits. It helps users analyze category-wise and brand-wise performance, compare order statuses, and explore sales distribution across different states using interactive filters and visualizations.

# 3. Tech Stack

The dashboard was built using the following tools and technologies:

- 📊 **Power BI Desktop** – Data visualization and interactive dashboard creation.
- 🧹 **Power Query** – Data cleaning, transformation, and preparation.
- 🧮 **DAX (Data Analysis Expressions)** – Calculated measures and KPI calculations.
- 📈 **Data Modeling** – Organizing data and establishing relationships between tables, where applicable.
- 🗺️ **Power BI Maps** – Geographic visualization of sales by state.
- 📉 **Charts and Slicers** – Interactive analysis of sales, categories, brands, supervisors, and order statuses.

# 4. Key Dashboard Features

- **KPI Cards:** Display Total Sales, Total Cost, Total Quantity, Transactions, and Total Profit.
- **Category Analysis:** Analyze total quantity across product categories, including Monitor, CPU, Mouse, SSD, and other products.
- **Sales by State:** Visualize geographic sales distribution using a map.
- **Brand Performance:** Compare sales across brands such as Intel, Samsung, Dell, Nvidia, Acer, and Gigabyte.
- **Order Status Analysis:** Analyze costs across Order, Delivered, Shipped, and Processing statuses.
- **Supervisor Filter:** Filter dashboard results by individual supervisors.
- **Interactive Visualizations:** Explore data using charts, slicers, and cross-filtering.
